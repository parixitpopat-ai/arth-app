Honest note: Arth's real icon system today is emoji, not a custom icon font/SVG set. A "high-fidelity" pass should decide explicitly whether to keep emoji (fast, zero-asset-cost, already consistent) or commission real icons — not silently swap mid-design.
Motion Guidelines — all real, built this session
Bottom Sheet: slide up + fade backdrop, 0.22s cubic-bezier(0.32, 0.72, 0, 1)
Toast: fade + 12px rise on enter, ~2.2s auto-dismiss
Button press: scale(0.97), 0.08s ease, universal via global CSS
FAB press: scale(0.88), 0.12s springy cubic-bezier(0.34, 1.56, 0.64, 1) — chosen by direct side-by-side comparison
Sync spinner: continuous rotate, 0.8s linear, only visible when cloudBusy
