4. Chart System 🔴 Future — was completely missing, genuinely new
LINE — Net Worth Growth
FORECAST — dashed = projected
● = Today's marker, always highlighted
PIE — Category Split
BAR — Monthly Spend
Rules: positive values always accent green · negative always danger red · forecast/projected segments always dashed with a solid "today" marker · Recharts already a library dependency, reduces build cost.

9. Icon Strategy
Current implementation: Emoji — confirmed as the real, actual icon system today, not a placeholder.
Target: Dedicated icon set (Material Symbols, Lucide, or custom) — not yet decided, not yet started. Kept as emoji through this entire design phase deliberately, since it's fast, zero-asset-cost, and already visually consistent — but this is a real decision to make explicitly before high-fidelity mockups get too far, not something to swap silently mid-design.
